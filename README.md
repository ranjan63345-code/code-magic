# Tasks – Flutter To-Do App

A clean, professional to-do application built with Flutter (Material 3).

## Features
- Add, edit, complete and delete tasks (swipe left to delete, with Undo)
- Priority levels (Low / Medium / High)
- Filter by All / Active / Done, clear completed
- Daily progress header
- Tasks persist locally via `shared_preferences`

## Run
```bash
flutter pub get
flutter run
```

## Test
```bash
flutter analyze
flutter test
```
